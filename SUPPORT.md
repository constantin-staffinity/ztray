# Support policy

ztray supports Zig 0.16.0 and newer on the current macOS, Windows, and Linux desktop environments covered by CI.

Native behavior depends on operating-system APIs and, on Linux, the active desktop environment, session D-Bus, AppMenu registrar, StatusNotifier watcher, and compositor. Reproducible issues on supported environments are prioritized.

Support is provided through GitHub issues. Security reports must follow `SECURITY.md`.

Breaking API changes are reserved for a future major version. Before 1.0, behavior and API changes may occur in minor releases and will be documented in `CHANGELOG.md`.
